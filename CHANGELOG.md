# Changelog

## 0.1.1

- **Shortcut clash, explained once.** If another app already uses Ctrl+Alt+Space (the Claude desktop app does),
  Zoomies switches to a free shortcut, remembers it, and tells you which one to press — once, instead of a warning at
  every start.
- Release builds no longer include the developer-only screenshot and demo switches.
- Build hygiene: GitHub Actions pinned to exact versions, read-only CI token, release notes from this changelog.

Installed copies of 0.1.0 update to this version by themselves.

## 0.1.0

First public release.

- **Quick Jump** (Ctrl+Alt+Space): jump to any folder or file from anywhere, including Open and Save dialogs.
- **Organize** a messy folder by type or by month, with a preview first and your own folder names (e.g. `.stl` → `3D Prints`).
- **Clean up** unused files, duplicates, large files, old installers and empty folders — to the Recycle Bin, never deleted outright.
- **Undo** anything from History. **Workspaces** reopen a set of File Explorer windows in one click.
- Installer with no admin rights, Start menu entry, start with Windows, and automatic updates from GitHub Releases.
